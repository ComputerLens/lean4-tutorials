# Lean 4 Tutorials · Computer Lens

Welcome to the Lean 4 tutorial series from **Computer Lens**.

Lean 4 is both a functional programming language and an interactive theorem prover. In this series, we explore programming, mathematics, formal verification, and computer-assisted proofs through practical examples.
